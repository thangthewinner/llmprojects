# llmprojects
This is a self-study repository focused on everything related to **Large Language Models (LLMs)**.

## How to use:
To run the projects in this repository, it's recommended to use **Ollama** (a local LLM runner) and install model *Llama3.2*.

1. Visit [https://ollama.com](#) and follow the installation instructions for your operating system.
2. Then run the following code in your terminal to install *Llama3.2:3b* model (2GB):
- `ollama run llama3.2:3b`. You can now chat with it just like with other AI chat interfaces.
- To exit AI chat, type: `\bye`. 

Then you must install **Anaconda** to manage python enviroments. You can install it throught: [https://docs.anaconda.com/anaconda/install](#).

**Set up envioremnet:**

1. `conda create -n llms python=3.12`
2. `conda activate llms`
3. `pip install -r requirements.txt`

Now you can explore projects.
